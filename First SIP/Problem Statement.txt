Build a modern, interactive, production-ready web application called **"Groww SIP Retention — AI Discovery Engine"**. 
This app is a PM Discovery & Opportunity Sizing Engine designed to uncover why first-time mutual fund investors in India drop off before completing 12 monthly SIP instalments on Groww, strictly adhering to SEBI constraints (NO fund/stock recommendations, NO fear/FOMO/urgency nudges).

### TECH & DESIGN REQUIREMENTS
- Clean, modern Fintech analytical dashboard UI (Dark Navy `#0F172A` & Slate `#F8FAFC` theme with Okabe-Ito color-blind-safe accents: Teal `#0072B2` for positive/verified, Vermilion `#D55E00` for high-severity churn, Amber `#E69F00` for medium risk).
- Fully functional interactive frontend (React / Next.js / Tailwind CSS + Lucide Icons) that works out-of-the-box for mentors testing the live URL without requiring them to enter their own API key (include an optional Groq/OpenAI/Gemini API key input in a settings drawer, plus a built-in deterministic + rule-augmented AI simulation engine so the live workflow NEVER fails during mentor grading).

### CORE FEATURES & 4 INTERACTIVE TABS

#### TAB 1: Live Interactive Discovery Workflow (Mentor Test Sandbox)
Allow any mentor or user to test the 4-stage AI Discovery Pipeline on a single input or a batch of raw inputs:
1. **Input Controls:**
   - A text area where a mentor can type/paste any raw user review, Reddit post, or Hinglish comment about SIPs.
   - 5 "Quick Load Real Verbatim" chips (e.g., Hinglish CIBIL/bounce fear, T-1 PhonePe mandate revocation, Month 5 flat return frustration, Salary date mismatch on the 25th, Request for best small-cap fund).
   - A "Run 4-Stage Discovery Pipeline" button.
2. **Visual 4-Stage Pipeline Execution (Animated Step-by-Step Cards):**
   - **Stage 1: PII Scrubber & Hinglish Semantic Normalizer:** Shows raw text -> scrubbed & translated English semantic intent.
   - **Stage 2: Indian MF Domain Rule Injector (NPCI / BSE StarMF Context):** Highlights domain mechanics detected (e.g., `T-3 Bank Mandate Lock-in Cutoff`, `₹295–₹590 Bank NACH/ECS Bounce Fee`, `UPI Autopay External Revocation`, `NAV Unit Averaging vs Absolute P&L`).
   - **Stage 3: Structured Behavioural Extraction (JSON + Visual Badges):**
     - `Investor Lifecycle Stage`: [Month 0-1 | Month 2-4 | Month 5-8 (Valley of Death) | Month 9-12]
     - `User Segment`: [Young Salaried 22-28 | Irregular Income/Freelancer | Family-Influenced]
     - `Primary Friction Theme`: (Mapped to 1 of 5 canonical clusters)
     - `Inside-App Confusion`: What worried them in Groww
     - `Outside-App Workaround`: What they did outside Groww (e.g., revoked mandate in PhonePe/GPay, switched to manual lumpsum, asked Reddit)
     - `Churn Severity Score`: 1 to 5 scale with rationale
   - **Stage 4: Constraint Check & Opportunity Contribution:**
     - Checks against Case Constraints (`No Fund/Stock Advice`, `No FOMO/Urgency`). If the user is asking "which fund to buy", flags it as `Constraint Restricted (0.2x weight)`.
